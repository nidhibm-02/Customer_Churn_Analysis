# Customer Churn Analysis and Prediction Using Machine Learning

## 📌 About

Analyzed **7,043 customer records** to understand churn patterns and developed machine learning models to predict customer churn risk.

## 🛠 Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## 📊 Analysis

- Exploratory Data Analysis (EDA)
- Chi-square statistical analysis
- Cramér's V
- Customer segmentation

## 🤖 Machine Learning

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

## 📈 Results

**Tuned Gradient Boosting achieved ROC-AUC: 0.8462**

## 🎯 Risk Analysis

Identified **185 high-risk customers** in the test set.
